# Karate Club: recovering known communities

Seven community detection algorithms run on Zachary's karate club network, scored by AMI against the known split and by modularity. Girvan-Newman matched the real groups best (AMI about 0.83). Leiden and Louvain produced the highest modularity (about 0.42) while matching the true labels less closely.
